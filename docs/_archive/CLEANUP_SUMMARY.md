## 📝 **Maintenance Guidelines**

### **Update Process**
1. **Identify Category**: Determine which consolidated document needs updating
2. **Make Changes**: Update the appropriate consolidated document
3. **Update Index**: Modify main README.md if structure changes
4. **Archive Old**: Move outdated individual files to archive/ if needed

### **File Naming Convention**
- **Consolidated Files**: `TOPIC_CONSOLIDATED.md`
- **Supporting Files**: Descriptive names with dates when relevant
- **Archive Files**: Original names preserved in archive/ directory

### **Directory Structure Rules**
- **Core**: Essential information and navigation
- **Status**: Current state and progress tracking
- **Technical**: Implementation details and architecture
- **Strategy**: Business and technical planning
- **Development**: Development guides and implementation
- **Operations**: Operational procedures and infrastructure
- **Archive**: Historical and legacy documents
