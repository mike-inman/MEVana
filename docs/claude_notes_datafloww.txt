  - ✅ Queue System: AsyncHistoryBuffer is implemented for off-hotpath database writes
  - ✅ Database Schema: arbitrage_opportunities table exists and is properly structured

  Primary Issue: Aggressive Filtering Preventing Data Flow

  The main culprit is the SmartFilter in hotpath_arb_engine/src/smart_filter.rs. Current default settings are:

  min_profit_bps: 15,           // 15 bps minimum (very high)
  min_net_profit_sol: 0.001,   // $0.20 minimum profit (high) 
  max_profit_bps: 100,         // Rejects "suspicious" opportunities
  min_venue_success_rate: 0.0, // Starts permissive but becomes restrictive

  Secondary Issues

  2. Competition detection can reject opportunities unnecessarily
  3. Database configuration requires proper environment variables
